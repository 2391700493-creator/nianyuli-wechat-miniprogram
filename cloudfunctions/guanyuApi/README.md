# 云函数更新

修改后，在微信开发者工具中右键 `cloudfunctions/guanyuApi`，选择“上传并部署：云端安装依赖”。仅重新编译小程序不会更新云函数。

心情管理使用 `saveMoods` 保存名称和颜色，`list` 返回当前用户的心情配置。配置保存在 `user_settings` 集合，首次访问时由云函数创建；若环境不允许自动创建，请在云开发数据库中手动创建同名集合，保留仅服务端访问权限。用户身份取自微信上下文。

部署后验证：在“快速记录 → 管理心情”修改颜色、添加心情，退出再进入确认设置保留；选中新心情保存事件；删除该心情选项后，原事件仍应能编辑保存。

本次还加入新建人物、事件的请求去重，以及心情版本的事务校验。请先部署云函数，再重新编译小程序。验证弱网重试不重复创建；连续调色后重新进入仍为最后的颜色；同步失败后通过“重试”恢复。客户端未确认的新建编号和心情改动会暂存在本机。
